1. Hybrid Retrieval
Determine:
- Is vector retrieval implemented?

- Is RRF actually used?
- Where does this happen?

- Does a reranker exist?
- What interface does it use?
- Is it deterministic, model-based, or both?

- At what point in retrieval?

- Is production behavior tested?

3. Query Expansion
Determine:
- Does query expansion exist?
- How are expanded queries generated?
- Is expansion deterministic or LLM-based?
- Is it actually used?
- Are multiple queries retrieved?
- Are results merged/deduplicated?
- Is this behavior covered by tests?

4. Context Optimization
Determine:
- How chunks are selected after retrieval.
- Whether duplicate/redundant chunks are removed.
- Whether context has a token/size budget.
- Whether source metadata survives optimization.
- Whether citation information survives.
- Whether context ordering is deterministic.
- Whether the context builder is actually used by RAGAgent.

5. RAG Evaluation
Determine:
- What RAG evaluation currently exists.
- Whether retrieval quality is measured.
- Whether context relevance/coverage is measured.
- Whether answer groundedness is measured.
- Whether citation correctness is measured.
- Whether evaluation is deterministic.
- Whether evaluation runs automatically.
- Whether evaluation results are persisted.
- Whether evaluation metrics are exposed through the API/observability layer.
